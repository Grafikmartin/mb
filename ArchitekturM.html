Architektur M

ARCHITEKTUR M ist mein selbstständig erarbeitetes Projekt, das ich mit Angular 21 entwickelt habe – einer Technologie, die nicht Teil des Lehrplans war. Der Standard war React.

Technische Umsetzung:
- Frontend: Angular 21 mit TypeScript, Standalone Components
- State Management: Angular Signals
- Routing: Hash-based Routing für GitHub Pages
- Styling: CSS Custom Properties (Design Tokens), responsive Design
- Deployment: GitHub Pages mit Custom 404-Fallback

Besondere Features:
Modulares Komponentensystem, responsive Mobile-first Design, CSS-Animationen, Material Icons, separate Impressum/Datenschutz-Seiten, TypeScript mit Strict Mode.
